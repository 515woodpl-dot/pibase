# M4 operations — in progress

## Status

This is a partial M4 implementation on branch `pibase/m4`. The operator
inventory and request-usage slice is complete; the M4 gate is not yet open.

## Built

- `project-list` reports project id, name, database, creation time, and the
  configured database quota. API keys and encrypted JWT material are excluded.
- `project-usage <project-id>` reports daily request counters for the last 30
  days and fails for an unknown project.
- Both commands require `PIBASE_ADMIN_DATABASE_URL` and are not HTTP endpoints.
